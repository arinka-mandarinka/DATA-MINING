# Правовой чек-лист (12 пунктов)

1. **Источники:** `books.toscrape.com` (учебная площадка) и `openlibrary.org/search.json` (открытый публичный API).
2. **Цель сбора:** учебный исследовательский проект по анализу книжного каталога и библиографических метаданных.
3. **Условия использования (ToS):** оба источника разрешают автоматизированный доступ без коммерческой эксплуатации.
4. **robots.txt:** на `books.toscrape.com` файл отсутствует (404); на `openlibrary.org` используется официальный API-эндпоинт `/search.json`.
5. **Авторизация:** сбор ведётся строго без авторизации, только публичные страницы и открытый API.
6. **Отсутствие обхода защиты:** капчи, антибот-защиты, ротация IP и маскировка `User-Agent` не применяются.
7. **Объём и частота:** ограничение скорости (`0.35–0.5 с` + джиттер), `gzip`, условные запросы (`ETag`/`Last-Modified`), запуск не чаще 1 раза в сутки.
8. **Состав данных и ПДн:** персональные данные пользователей не собираются; в API присутствуют только публичные имена авторов книг.
9. **Основание обработки:** учебная и исследовательская деятельность с общедоступными библиографическими данными.
10. **Место и срок хранения:** локальное хранилище SQLite/Parquet на компьютере студента; удаление после защиты проекта.
11. **Контакт:** указан в заголовке `User-Agent` (`DataMiningCourseBot/1.0 ...`).
12. **Действия при претензии:** немедленная остановка расписания в n8n, прекращение запросов к домену и удаление локальных копий по запросу правообладателя.
