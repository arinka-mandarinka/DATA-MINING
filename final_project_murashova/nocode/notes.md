# No-code компонент (n8n)

## Расписание
- **Триггер:** `Schedule Trigger` — запуск 1 раз в сутки в 03:00.
- **Обоснование:** каталог `books.toscrape.com` и библиографическая база `Open Library` обновляются редко; суточный инкрементальный прогон минимизирует нагрузку и использует условные запросы (`304 Not Modified`).

## Таблица распределения этапов (код vs no-code)

| Этап пайплайна | Реализация | Что не удалось / нецелесообразно переносить в no-code |
| :--- | :--- | :--- |
| Расписание и мониторинг прогонов | **no-code (n8n)** | В актуальной версии локального n8n нода `Execute Command` и прямой доступ к диску отключены политикой безопасности, поэтому запуск Python выполняется отдельно, а n8n забирает JSON-отчёт по локальному HTTP. |
| Сбор HTML (`books.toscrape.com`) | **код (Python)** | Устойчивые CSS-селекторы, джиттер, `ETag`/`Last-Modified`, Circuit Breaker и возобновляемость по категориям. |
| Сбор API (`openlibrary.org`) | **код (Python)** | Нормализация названий, дедупликация запросов через `watermark.json`, обработка `Retry-After`. |
| Очистка и контракт (`Pydantic`) | **код (Python)** | Строгая типизация, пользовательские валидаторы, маршрутизация брака в `rejects.jsonl`. |
| Хранилище (SQLite UPSERT) | **код (Python)** | Транзакционный `ON CONFLICT DO UPDATE` и построение витрин `mart`. |
| Метрики качества и гейт `mart` | **код (Python)** | Комплексная проверка 6 порогов и блокировка витрины при статусе `RED`. |
| Проверка вердикта и оповещение | **no-code (n8n)** | — |

## Инструкция по импорту и проверке
1. Запустите локальный HTTP-сервер в папке с отчётами:
   `cd reports && python -m http.server 8000`
2. Откройте n8n и выберите **Import from File** → `nocode/workflow.json`.
3. В ноде **Fetch Run Report (HTTP)** проверьте URL отчёта (например, `http://127.0.0.1:8000/run_report_20261124T081314Z.json`).
4. Нажмите **Execute** — при вердикте `GREEN` цепочка пройдёт по ветке `true` в **Log Success Notification**, при `RED` — в **Log Alert Notification**. Скриншот выполнения сохранён в `nocode/screenshots/`.
